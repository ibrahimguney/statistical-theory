\chapter{Solutions to the Exercises}\label{ek:cozumler}

This appendix contains solutions to all the exercises in the book. The heading of each solution links to the exercise, and the ``$\rightarrow$\,Solution'' link at the end of each exercise leads here. Where an exercise asks for numerical values or a simulation, the values given were obtained by actual computation; simulation results may differ in the last digits depending on the random seed. The same libraries as in the chapters (\texttt{numpy}, \texttt{scipy}) are used; short code is given only where it is part of the solution.

The solutions are kept as short as possible, but each step names the result in the book on which it rests. When the claim of an exercise holds only under certain conditions (e.g.\ Exercise~\ref{exr:13-3}), the solution states those conditions explicitly.
