# Theory of Statistics

[![Book check](https://github.com/ibrahimguney/statistical-theory/actions/workflows/check.yml/badge.svg)](https://github.com/ibrahimguney/statistical-theory/actions/workflows/check.yml)

LaTeX sources, Python code and Jupyter notebooks of *Theory of Statistics — Axiomatic Foundations,
Proofs and Computational Applications* by İbrahim Güney: a 23-chapter book on mathematical
statistics, from measure-theoretic probability to point estimation, hypothesis testing, interval
estimation, Bayesian inference and decision theory. This is the English edition of
*İstatistik Teorisi*; chapter structure, labels, code and numerical outputs are identical in the
two editions.

- **PDF:** [`main.pdf`](main.pdf). The version recompiled on every push can be downloaded as
  `statistical-theory-pdf` from the "Artifacts" section of the corresponding
  [Actions](https://github.com/ibrahimguney/statistical-theory/actions) run.
- **Notebooks:** [`notebooks/`](notebooks/) — the computational applications of each chapter,
  with executed outputs. They can be opened in Colab with the links below.

## Building
    pdflatex main.tex
    python3 tools/make_index.py compile   # main.idx -> main.ind (subject index)
    pdflatex main.tex
    pdflatex main.tex

Each chapter can also be compiled on its own (`pdflatex ch07_point_estimation_mse.tex`); this is
provided by the `subfiles` package, and the chapters take the common preamble from `main.tex`.

Required packages: babel-english, lmodern, amsmath/amsthm/mathtools, listings, enumitem, subfiles,
graphicx, hyperref, tcolorbox, longtable, makeidx.

## Structure
- `main.tex` — preamble, theorem environments, macros (\E, \Var, \iid, \pto, \dto, ...)
- `preface.tex` — preface and notation table
- `chXX_*.tex` — the 23 chapters (`ch01` … `ch23`)
- `app_a_distributions.tex` — Appendix A: table of common distributions
- `app_b_solutions.tex` (+ `_1`, `_2`, `_3`) — Appendix B: solutions to all 93 exercises.
  Exercises carry the label `exr:CC-k` and solutions `coz:CC-k` (CC = chapter number,
  k = position). If you add an exercise, label it the same way and add
  `\begin{solution}{CC-k} ... \end{solution}` to Appendix B.
- `bibliography.tex` — bibliography
- `figures/` — figures produced by the Python code (PDF)

Labels (`thm:...`, `ex:...`, `ch:...`) are the same as in the Turkish edition, so a change in one
edition can be located in the other by its label.

## Code
All Python code is in the `code/chXX/*.py` files (69 files) and is shown in the book by the
`\pycode{...}` command. See `code/README.md` for setup, running and file naming. The "Output"
boxes under the code blocks were produced by actually running the code.

## Tools (`tools/`)
- `run_blocks.py` — runs the `\pycode{...}` files of a chapter and refreshes its "Output" boxes:
  `python3 tools/run_blocks.py ch05_inequalities_lln.tex` (whole book: `ch*.tex`)
- `make_index.py` — subject index. `python3 tools/make_index.py add` removes all `\index`
  commands from the chapter files and reinserts them according to the `TERIMLER` list: each term
  is indexed at its first occurrence in each `\section`, occurrences in definition titles get a
  bold page number; mathematics, code, headings, summary boxes and the Exercises are not scanned.
  `python3 tools/make_index.py compile` produces `main.ind` from `main.idx`. To add a term, append
  `("displayed form", r"regular expression", chapter-set-or-None)` to the list and run `add`.
- `make_notebooks.py` — generates the `notebooks/ch_XX.ipynb` notebooks from the `code/` files and
  the chapter text: `python3 tools/make_notebooks.py --run` (generate and execute), `--check`
  (fails if the notebooks are out of date). Compile the book first; reference numbers in the text
  are taken from `main.aux`. Do not edit the notebooks by hand.
- `check_log.py` — fails if `main.log` contains undefined references/citations or overfull boxes
  above 4pt.
- `sync_editions.py` — keeps this edition in step with the Turkish one (istatistik-teorisi); see
  "Keeping the two editions in step" below. The same file is `araclar/baski_esle.py` in the
  Turkish repository.
- `translate_code.py` — helper used to produce the English code files from the Turkish edition
  (string replacements, with a check that no Turkish text remains).

## Keeping the two editions in step
Both editions share chapter numbers, code numbering and every `\label`, so a place in one edition
can be found in the other by its label. With both repositories cloned side by side
(`statistical-theory/` and `istatistik-teorisi/`, or point to the other one with `--other PATH`):

    python3 tools/sync_editions.py changes --from tr   # what changed in the Turkish edition since
                                                        # the sync point, and where it goes here
    python3 tools/sync_editions.py check                # structural comparison of the two editions
    python3 tools/sync_editions.py mark                 # record the new sync point

- `changes` lists, for every file changed since the last sync point (uncommitted changes
  included), the place in the other edition: the label of the theorem/example/exercise
  (edits inside a proof are attributed to the theorem it proves), unlabelled environments by their
  position in the section, the chapter introduction, code files and Output boxes, all with line
  numbers in the target file. New labels are reported with the label they should follow; deleted
  labels and environments are reported too. `--from en` gives the reverse direction;
  `--since REV` uses another starting commit.
- `check` compares the editions structurally: labels of every chapter and appendix (set and order),
  citation keys, figures, the code files (token structure with identifiers, strings and comments
  ignored, so translated messages and renamed variables are fine but a changed number or call is
  not) and the numbers in every Output box. It exits with code 1 if anything differs.
- `mark` writes both current commits to `tools/sync_point.json`; commit that file.

Workflow: edit the Turkish edition and commit → `changes --from tr` → update the English edition
→ `check` until it reports no difference → `mark`, and commit `tools/sync_point.json`.

## Automatic checks (GitHub Actions)
`.github/workflows/check.yml` does the following on every push and pull request; if any step
fails the run shows red:
1. Runs all 69 code files and checks that the "Output" boxes in the book are up to date.
2. Warns if the index commands are out of date.
3. Compiles the book with its index; catches undefined references/citations and overfull boxes above 4pt.
4. Checks that every chapter compiles on its own.
5. Checks that the notebooks are up to date and runs them all.
6. Attaches the compiled PDF to the run.

Package versions in CI are pinned in `code/requirements-ci.txt`; the outputs in the book were
produced with these versions. If you upgrade them, rerun `run_blocks.py` and
`make_notebooks.py --run` and push the results together.

## After a change (summary)
| What changed | What to run |
|---|---|
| A Python file | `python3 tools/run_blocks.py chXX_*.tex` and `python3 tools/make_notebooks.py --run` |
| Text | `python3 tools/make_index.py add`, then compile |
| Order of chapters/theorems | compile twice; labels are resolved automatically |
| The Turkish edition | `python3 tools/sync_editions.py changes --from tr`, update, `check`, `mark` |
